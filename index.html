作成条件

自動作成で必ず守る条件です。公休日数は月ごとに入力してください（休み希望も公休に含みます）。

希望を登録（休み・勤務）

勤務表のマスをタップしても登録できます。登録した希望は、自動作成で必ず守ります。

スキル配置のルール

デモ用の設定です。リーダーとドライバーの資格を持つスタッフを考慮して、日勤・夜勤の不足をチェックします。

この試作品の範囲

✓ 月間勤務表の表示・編集
✓ 夜勤明けの自動入力
✓ 希望（休み・日勤・夜勤）の登録・保護
✓ 必要人数と資格のチェック
✓ CSV出力・端末内保存
✓ 条件を満たす勤務表の自動作成（希望を維持）
✓ 作成条件の設定（公休日数・最低人数・個人の夜勤回数）

未実装：前月・翌月の引き継ぎ、連続勤務の上限などの労務条件、ログイン、承認、通知、複数人同時利用、Excel/PDF出力、院内ネットワーク制御。
