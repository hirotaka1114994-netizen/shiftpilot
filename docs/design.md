# デザイン指針

既存の `index.html` から取り出した現行デザインです。新しい画面や部品はこれに合わせます。
大幅な変更（配色の変更、レイアウトの組み替えなど）は、提案して承認を得てから行います。

## 対象端末
- 現状：パソコン（幅1500pxまで）を中心に作られており、950px以下・560px以下で段組みが変わる。
- スマホ：対応を意図した設定はあるが、**幅390px前後では勤務表のせいで画面が横に広がる不具合あり**（`docs/progress.md` 参照）。
- 想定する利用者と端末の割り当ては未確定（`docs/requirements.md` C-5）。

## 文字
- 書体：端末標準（-apple-system, Helvetica Neue, sans-serif）。
- 大きさの目安：ロゴ26px、見出し16〜25px、本文13〜14px、補足12px。
- 現状は勤務表10〜12px、注記11〜12pxと小さめ。スマホでは**本文14px以上、補足12px以上**を目安にする。

## 余白・形
- カード：角丸16px、内側の余白17px（スマホ12px）、枠線1px。
- ボタン：角丸10px、余白 縦10px×横13px、太字。
- 要素の間隔：8〜15px。

## ボタンの種類
| 種類 | 見た目 | 用途 |
|---|---|---|
| 主ボタン `.primary` | 青地・白文字 | その画面の主な操作 |
| 強調ボタン `.dark` | 濃紺地・白文字 | 登録などの確定操作 |
| 控えめボタン `.ghost` | 薄い青地 | 初期化など補助的な操作 |
| 標準 | 白地・紺文字 | その他 |

## 入力方法
- 勤務の変更：マスをタップ → ダイアログで区分ボタンを選ぶ（手入力なし）。
- 希望休：スタッフと日付をプルダウンで選んで登録。
- 確認・警告：現在はブラウザ標準の `alert` / `confirm`。新しく作る場合も同じ動きにそろえる（変更する場合は提案してから）。

## スマホでの配慮（新規・改修時のチェック項目）
- 押せる部分は44px四方以上（現状の勤務表のマスは約34×35px）。
- 片手で操作しやすいように、主な操作は画面の下寄りか、ダイアログ内に置く。
- 入力はなるべく選択式にし、文字入力を減らす。
- 横スクロールは勤務表の中だけにとどめ、ページ全体は横に広がらないようにする。
