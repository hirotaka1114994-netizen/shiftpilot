# 引き継ぎ（作業終了時）

## 手順
1. **動作確認**：`node tests/smoke.cjs` と `node tests/generate.cjs` を実行し、結果（○/○項目OK、NG項目）を控える。
   - 既知のNG（`docs/progress.md` の「既知の問題」）と、新しく増えたNGを区別する。
2. **変更点の確認**：`git status` と `git diff --stat` で、今回変えたファイルを把握する。
3. **`docs/progress.md` を更新**：
   - 「現在の状態」の最終更新日・テスト結果・次にやることを書き換える。
   - 「既知の問題」：直したものは削除して作業記録に移す。新しく見つけたものは追加する。
   - 「作業記録」の先頭に、日付つきで次の4点を書く：
     - 完了したこと
     - 確認結果（**確認できたこと**と、**未確認のことと理由**を分ける）
     - 残る問題
     - 次にやること
   - 要件の状態が変わった場合（利用者の承認など）は `docs/requirements.md` も更新する。
4. **コミット・プッシュ**：内容がわかる日本語のメッセージでコミットし、指定の作業ブランチへプッシュする。
5. **利用者への報告**：結論 → 確認結果（確認済み／未確認）→ 残る問題 → 次の候補、の順で簡潔に。

## 注意
- 実行していないテストや見ていない画面を「確認済み」と書かない。
- 進捗記録は事実のみ。推測は「〜の可能性」と明記する。
