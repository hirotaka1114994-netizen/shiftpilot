# 画面の確認・改善

## 1. 変更前の確認
- `docs/design.md` を読み、使う色・ボタン・余白を既存のものから選ぶ。
- 新しい色・部品・レイアウトの組み替えが必要な場合は、**実装前に提案**する（変更前後の違いと理由を短く示す）。

## 2. スクリーンショット
- `node tests/smoke.cjs` を実行すると `tests/screenshots/desktop.png`（PC幅）と `tests/screenshots/phone.png`（iPhone 13 相当）が保存される。
- 変更した部分が写らない場合は、Playwright で該当部分（ダイアログを開いた状態など）を追加で撮影する。保存先は `tests/screenshots/`（Git管理外）。
- 撮影した画像は自分で開いて目で確認する。利用者に見せる画像は `deviceScaleFactor: 2` で撮る。

## 3. チェック項目
- [ ] 勤務区分の色が `docs/design.md` の表どおり
- [ ] ボタンの種類（主・強調・控えめ）の使い分けが既存と同じ
- [ ] スマホで本文14px以上、補足12px以上
- [ ] スマホで押す部分が44px四方以上（難しい場合は理由を報告）
- [ ] スマホでページ全体が横に広がらない（勤務表の中の横スクロールは可）
- [ ] 文字入力を増やしていない（選択式を優先）
- [ ] 画面上のエラー（コンソールエラー）がない

## 4. 報告
- 確認した画面幅と、確認できなかったこと（例：実機のスマホでは未確認）を分けて伝える。
- 改善の余地があれば、優先度つきで `docs/progress.md` の改善案に追記する。
